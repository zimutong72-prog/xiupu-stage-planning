# 秀谱｜舞台策划 Skill

## 项目解决什么问题

秀导需要把口头创意、节目资料和各工口的意见反复整理进同一份方案。音乐晚起、演员换装或灯光提示变更时，往往还要手动检查其他安排是否受影响。秀谱是一个在 Codex 对话中使用的舞台策划 Skill，帮助秀导减少找参考、写方案和同步改稿的重复工作。

## 主要功能

- **梳理创意和需求**。从口头想法和已有资料里提取关键画面、已确认条件和待确认项，帮助秀导选定概念。
- **起草方案和 Q 表**。将节目拆成具体时段，写清音乐、台词、人员与调度、视觉、灯光和道具。
- **按方案找参考**。方案确认后，可用当前会话的检索工具找实拍、正片、切片或参考图，标明对应段落、推荐理由和适配方式。检索工具不可用时，提供可直接使用的搜索词。
- **定稿和持续改稿**。方案与参考讨论后，由秀导确认 V1。排练、彩排和执行中收到反馈时，预览受影响的 Cue 和工口，确认后生成新版并记录最终执行结果。

## 安装方法

将整个 `xiupu-stage-planning` 文件夹复制到本机 Codex 的 Skills 目录 `~/.codex/skills/`，保留其中的 `SKILL.md`、`agents/` 和 `references/`。如本机设置了 `CODEX_HOME`，请复制到其下的 `skills/`。以下命令在秀谱项目根目录运行。

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./xiupu-stage-planning "${CODEX_HOME:-$HOME/.codex}/skills/"
```

本项目由 Markdown 指南和 YAML 配置组成，可以直接在 Codex 会话中使用。也可以在对话里指定读取 [SKILL.md](xiupu-stage-planning/SKILL.md) 来试用。

## 使用方法

在 Codex 对话中输入 `$xiupu-stage-planning`，并提供节目想法、已有资料和当前阶段。局部改稿时，附上最新确认版、反馈和需要锁定的安排。排练或现场有变化时，将问题和发生时间反馈到对话中即可继续改稿。

工作流程为说想法 → 整理需求 → 讨论并确认概念 → 确认方案和 Q 表 → 找参考并写明理由 → 讨论后定稿 V1 → 跟进排练和现场修改直到执行结束。

## 输入输出示例

| 输入 | 输出 |
| --- | --- |
| 「想做纸灯开场，先看到一个人的影子，后来变成一片灯海。人数和时长未定。」 | 一句话概念、关键画面、人数和时长等待确认项。 |
| 「概念已确认，开场 30 秒、8 人、两侧入场、无道具，先分批再合拢。」 | 开场、两批入场、合拢与收束的方案和七列 Q 表草稿。方案确认后，可按段补实拍链接、推荐理由和适配方式。 |
| 「V1 锁定 00:36 全台亮。彩排主持讲到 00:39，音乐要等主持结束，演员跟第一拍进。」 | 音乐和演员需联动调整的预览，以及全台亮早于入场的冲突。秀导确认后形成新版。 |
