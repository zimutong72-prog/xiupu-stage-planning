# 舞台参考检索

## 默认检索范围

优先找现成的舞台实拍、节目正片和切片。按要参考的细节选来源，无需逐个平台搜一遍。

| 要参考什么 | 优先找什么 | 从哪里找 |
| --- | --- | --- |
| 舞蹈、走位、队形 | 舞台直拍、全景机位、排练片段 | 哔哩哔哩、YouTube 的舞团、演出机构或编舞者账号。抖音、小红书切片可辅助发现 |
| 演唱、编曲、合唱入场 | Live 现场、音乐综艺片段、完整演唱 | 哔哩哔哩、YouTube、节目官方频道及其播出平台 |
| 综艺、晚会的节目衔接 | 开场、串场、转场、观众互动片段 | 央视频、芒果 TV、腾讯视频、爱奇艺、优酷等官方正片或切片。用短视频平台定位节目与期数 |
| 镜头与导播 | 官方播出版、多机位成片、公开导播回看或制作解析 | 节目官方频道、哔哩哔哩、YouTube。可对照同一段的全景直拍和播出版，观察取景与切换 |
| 灯光、舞美、服装和屏幕视觉 | 舞台实拍关键帧、演出摄影、设计案例图 | 演出机构、制作团队、设计师的官方发布或项目页，也可定位到视频中的具体画面 |

切片能确认细节时可直接推荐，能追溯原节目时同时给出处。记录节目或作品名、期数或发布账号。图像可以指向视频的关键帧，说明在哪个画面截图。公开片段可作为视觉参考，实际转载或纳入交付物时记录素材的复用条件。若找不到贴切素材，才按需要补生成示意图的提示词。

## 检索与回填

1. 把作者的口语拆成段落、工口、想借的舞台手法和本项目限制。使用作者已有的资料与参考链接。若不确定他想借的是灯光、站位还是镜头，先说明判断。只有这会明显改变检索方向时才追问。
2. 把抽象描述变成可观察的画面或动作。用「场景 + 工口 + 可观察效果」构造查询。例如「天还蓝着，城墙已经暖起来」可分成「蓝调时刻 古城墙 暖色建筑灯 实拍」和「blue hour warm-lit city wall outdoor stage」。先找高匹配度参考，再考虑相近场景。外部查询使用通用特征，项目内部信息留在本地。
3. 根据用途选媒介。灯色、站位和服装可用静帧。音乐起点、镜头切换、进退场、灯光变化和观众互动优先找视频或音频。内部试听、试镜和未公开文件登记为已有项目素材，按权限使用。
4. 默认每个参考点给 1–3 条。打开候选来源，优先给原视频、原图或案例详情页，避免只给搜索结果。仅在核实画面或时间段时给具体时间码。页面可打开但媒体无法查验时，标注「待确认画面」，并说明判断依据。没有合适来源时给精确检索词，必要时附一段可用于生成示意图的提示词。
5. 保留原始方案列，附一份可贴回 Ref 栏的清单。每条写清「段落／Cue｜工口｜参考链接｜看哪里｜推荐理由｜只参考什么及如何适配｜核验状态」。例如一张合唱团图可能只参考站位，其灯光和服装按本项目另定。已有参考与新找链接分别标明，按项目约定记录复用条件。
